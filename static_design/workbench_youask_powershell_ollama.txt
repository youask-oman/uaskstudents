Quick cheat sheet

Changed code/Dockerfile/deps? → docker compose up -d --build

Changed .env / service config and it’s not taking effect? → docker compose up -d --force-recreate

Want fresh containers from scratch? → docker compose down && docker compose up -d --build

Docker itself is broken or networking is haunted? → restart Docker daemon
