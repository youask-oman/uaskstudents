Quick Start Guide

Integrate uask.ai into your application using this cURL example. Replace the token with your active key.

curl -X POST https://api.uask.ai/v1/query \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "What is the status?",
    "stream": true
  }'
