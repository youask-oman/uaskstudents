Problem 01 Quadratic Optimization

Problem Statement

Find the maximum value of the function f(x,y) = xy subject to the circular constraint g(x,y) = x^2 + y^2 - 1 = 0 using the method of Lagrange Multipliers.

Logical Progression

1
Set up the Lagrangian

Define the Lagrangian function by combining the objective function and the constraint with the multiplier λ.

L(x, y, λ) = xy - λ(x^2 + y^2 - 1)
2
Compute Partial Derivatives

Set the gradient of the Lagrangian equal to zero to find the critical points.

∂L/∂x = y - 2λx = 0
∂L/∂y = x - 2λy = 0
∂L/∂λ = -(x^2 + y^2 - 1) = 0
3
Solve the System

From (1) and (2), we get y = 2λx and x = 2λy. Substituting results in x^2 = y^2.

2x^2 = 1 ⇒ x = ±1/√2, y = ±1/√2
4
Evaluate Critical Points

Substitute critical points into f(x,y) to determine the maximum value.

Final Answer
f_{max} = 1/2
verified
Problem 02 Complex Definite Integral

Problem Statement

Evaluate the integral ∫[0 to 2] 1/(x^2 + 4) dx using trigonometric substitution.

Logical Progression

1
Trigonometric Substitution

Let x = 2 tan(θ), which implies dx = 2 sec^2(θ) dθ.

2
Change Limits of Integration

When x = 0, θ = 0. When x = 2, tan(θ) = 1, so θ = π/4.

3
Simplify Integrand

Substitute terms: ∫ (2 sec^2(θ))/(4 tan^2(θ) + 4) dθ = ∫ (2 sec^2(θ))/(4 sec^2(θ)) dθ.

∫[0 to π/4] (1/2) dθ
4
Definite Integration

Evaluate the simple integral at the boundaries.

[(1/2)θ] from 0 to π/4
Final Answer
π/8
verified
Problem 03 Differential Equations

Problem Statement

Solve the second-order linear homogeneous differential equation: y'' - 5y' + 6y = 0 with initial conditions y(0) = 2, y'(0) = 5.

Logical Progression

1
Characteristic Equation

Assume a solution of the form y = e^{rt}.

r^2 - 5r + 6 = 0
2
Find Roots and General Solution

Factor the quadratic: (r-2)(r-3) = 0. Roots are r_1=2, r_2=3.

y(t) = c_1 e^{2t} + c_2 e^{3t}
3
Apply Initial Conditions

Using y(0)=2 and y'(0)=5 to find coefficients.

c_1 + c_2 = 2
2c_1 + 3c_2 = 5
4
Solve for Coefficients

Solving the system yields c_1 = 1, c_2 = 1.

Final Answer
y(t) = e^{2t} + e^{3t}
