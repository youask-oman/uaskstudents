To solve the equation \(\sqrt{x+3} = x-3\), we will follow these steps:

**Step 1: Square both sides of the equation to eliminate the square root.**
\[
(\sqrt{x+3})^2 = (x-3)^2
\]
This simplifies to:
\[
x+3 = x^2 - 6x + 9
\]

**Step 2: Rearrange the equation to form a standard quadratic equation.**
Subtract \(x+3\) from both sides:
\[
0 = x^2 - 6x + 9 - x - 3
\]
Simplify the right side:
\[
0 = x^2 - 7x + 6
\]
So, we have:
\[
x^2 - 7x + 6 = 0
\]

**Step 3: Factor the quadratic equation.**
We need to find two numbers that multiply to 6 and add up to -7. These numbers are -1 and -6. Therefore, we can factor the quadratic as:
\[
(x-1)(x-6) = 0
\]
Setting each factor equal to zero gives us the potential solutions:
\[
x-1 = 0 \quad \text{or} \quad x-6 = 0
\]
Solving these equations, we get:
\[
x = 1 \quad \text{or} \quad x = 6
\]

**Step 4: Verify the solutions by substituting them back into the original equation.**

\[
\sqrt{6+3} = 6-3

\]
Since \(3 = 3\), \(x = 6\) is a valid solution.

\sqrt{1+3} = 1-3

Simplify both sides:
\[
\sqrt{4} = -2
\]
Since \(2 \neq -2\), \(x = 1\) is not a valid solution.

**Step 5: State the final answer.**
The only valid solution is \(x = 6\).

**Domain check:**
We need to ensure that the solution satisfies the domain constraints. The domain constraints are:

x + 3 \geq 0 \quad \text{and} \quad x - 3 \geq 0

Simplifying these, we get:
